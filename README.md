# Bike Sales Analytics Dashboard

## Project Overview
This project analyzes bike sales data using Excel, SQL, Python, and Power BI to identify sales trends and business insights.

## Tools Used
- Excel
- SQL
- Python
- Power BI

## Key Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Interactive Dashboard
- Sales Performance Analysis

## Key Insights
- Monthly Sales Trends
- Customer Analysis
- Product Performance
- Revenue & Profit Analysis
